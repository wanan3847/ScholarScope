/01架构设计

查询规划 → 多通道并行召回 → 语义预筛 → 大模型判分 → 引文扩展 → 精排输出，每一层可独立验证、可观测。

/02创新点

检索常驻机制 + 完整 Web 工作流

以成熟 SPAR 架构为基线改造的 SPAR2 引擎，六项常驻机制全程生效，并在 Web 端形成可用的研究工具。

引擎 01
多通道并行检索
arXiv / OpenAlex / CrossRef / Semantic Scholar / 本地语义五路并发，单通道 40s 硬超时，失败自动熔断降级。
召回
引擎 02
迭代检索（BFS）
最多 3 轮广度优先扩展，后续轮次聚焦 arXiv + OpenAlex + 本地，预算随轮次放宽。
召回
引擎 03
文档驱动查询生成
用已找到论文的标题提取判别词补充查询，零额外 LLM 成本。
查询
引擎 04
RefChain 双向引文
引用与被引同时扩展，API 模式找 2 跳，把综述型查询引向种子论文的上下游。
引文
引擎 05
BGE 语义预筛 + 保底
语义/词面/被引加权预筛，高语义分论文保证进入判分池，避免漏掉语义型 gold。
筛选
引擎 06
评测截止日期过滤
按 PaSa source_meta 时间约束过滤，避免评测日期之后的论文污染排序。
约束
