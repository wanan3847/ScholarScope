## 三、编辑与更新方法

### PDF 文档

- 直接编辑同目录的 `.docx`（宋体正文 / 黑体标题 / 温暖学术配色），改完在 Word 里「文件 → 另存为 PDF」即可；
- 目录为 Word 域代码：打开后如有页码出入，右键目录选择「更新域」；
- 简介全文 298 字，修改时请保持在 300 字以内（含标点）。

### 答辩 PPT

- 直接编辑 `樱花_樱花学术_答辩演示.pptx`（Office / WPS 均可）；
- 如需用 PPTD 源工程编辑并重新导出，运行：

```bash
npx open-kimi-ppt-skills serve
```

然后在浏览器打开 `http://127.0.0.1:55173/` 授权该目录即可（也可在编辑器内配置动画并导出 PPTX）。

### 视频

- 分镜表已给出 12 个镜头的画面与台词，按顺序录制真实系统即可（镜头 9 为真实检索演示，等待约 1 分钟）；
- 已附 `樱花_樱花学术_项目视频_演示片段.mp4`（真实系统：首页 → 搜索页 → 真实检索 → 结果页），可剪辑进镜头 1/2/5 并叠加配音台词；
- 建议分辨率 1920×1080、H.264 MP4、时长 ≤ 5 分钟、大小 ≤ 200M。
