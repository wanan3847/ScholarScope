# SakuraScholar 部署与运行说明

> 版本：v1.0 · 2026-08-24 · 环境要求：Python 3.10+（建议 3.10–3.13）、Node.js 18+（仅 UI 冒烟需要）、可选 Ollama（本地模型）

## 1. 安装依赖

```bash
cd src
pip install -r requirements.txt
```

## 2. 启动 Web 服务

```bash
cd src
python3 -m uvicorn web.app:app --host 127.0.0.1 --port 8765
```

浏览器打开 `http://127.0.0.1:8765/`（项目介绍首页）与 `http://127.0.0.1:8765/app`（搜索页）。

## 3. 配置真实 LLM（可选）

```bash
cp .env.example .env
# 编辑 .env：SAKURA_LLM_PROVIDER=deepseek；DEEPSEEK_API_KEY=sk-xxx
```

支持 provider：`mock`（默认，离线）/ `openai` / `deepseek` / `qwen_api` / `glm` / `qwen`（本地 Ollama）。

## 4. 官方测试集评测

```bash
cd src
# 快速验证（每个测试集前 10 条）
python3 run_eval.py --n 10 --benchmarks real_scholar auto_scholar paper_finder litqa2 \
  --real --llm deepseek --output /绝对路径/quick.json

# 全量（--n 传大数即全量；建议守护进程运行）
python3 run_eval.py --n 5000 --benchmarks real_scholar auto_scholar paper_finder litqa2 \
  --real --llm deepseek --output /绝对路径/full.json
```

注意：OpenAlex / Semantic Scholar 匿名额度按 UTC 零点重置，建议北京时间 08:00 后启动评测以获得全通道分数。

## 5. 单元测试

```bash
cd src
pytest tests/ -q    # 32 例，应全绿
```

## 6. UI 冒烟测试（可选，需先启动服务）

```bash
node src/tests/ui_smoke.js
```

## 7. 常见问题

- 评测输出请使用绝对路径（`results/` 在仓库根，相对路径可能 404）；
- 收藏/已阅等 ID 路由使用 `{paper_id:path}`，DOI 带斜杠可正常访问；
- 外部 API 额度耗尽时系统自动静默降级，属预期行为，可稍后重试；
- 本地语义索引补全：设置 `SAKURA_LOCAL_EMBED_RESUME=1` 后重跑检索即可续跑。
