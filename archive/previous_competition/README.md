# 旧比赛材料归档

本目录保存上一届比赛的历史材料，供查阅和复用项目事实。旧赛题的评分权重、评审维度、提交规范和时间安排仅适用于原比赛。

## 目录

- `materials/2026_sakurascholar_submission/`：上一届比赛提交包，包括作品简介、项目文档、答辩演示、视频素材和交付清单。
- `docs/赛题整理_旧赛制.md`：上一届比赛的赛题与评分规则整理。
- `docs/旧项目计划书.md`：按上一届赛题撰写的计划书，含旧评分维度和旧比赛叙事。
- `docs/旧架构方案.md`：包含旧比赛评分权重和面向原赛题组织的方案说明。
- `docs/superpowers/`：上一届 SPAR2 优化设计与实施计划，保留了原评分权重和目标。

## 使用约定

准备新比赛时，先以新比赛的官方通知、评分标准和提交要求为准。不要把本目录里的旧评分标准当作新比赛依据，也不要在新比赛材料中沿用旧权重或评审维度。系统 benchmark 的 F1、Recall 等实验记录仍维护在 `docs/评测记录.md`，它们是系统实验数据，不是竞赛评分标准。
