# 研索 ScholarScope 作品介绍视频脚本

> 时长 5 分钟（±15 秒），格式 MP4，1080p，麦克风直录即可。
> 录制方式：本机启动服务（`cd src && python3 -m uvicorn web.app:app --port 8765`），
> 浏览器 1920×1080 全屏录制 `/app`，按分镜操作；旁白与画面同步，不要念稿感。
> 录完后用 QuickTime 或剪映导出 MP4，命名见文末。

---

## 分镜 0　片头（0:00—0:12）

- 画面：PPT 第 1 页（从研究问题，到可核对的研究成果）。
- 旁白：
  “研究者每天要回答一个问题：这个领域哪几篇文献真的回答了我想问的问题。
  研索把检索、阅读和资料整理连成一条可追溯的链路。”

## 分镜 1　问题与定位（0:12—0:50）

- 画面：PPT 第 2 页（研究过程围绕问题持续推进）。
- 旁白：
  “现在的工具是断开的：检索在一处，阅读批注在另一处，写综述时又要重新找回依据。
  大模型可以读得快，但给出的理由常常无法核对，检索失败时甚至会编造论文。
  研索的做法是——每一条推荐、每一个结论，都能回到论文的标题、摘要或具体页码。”

## 分镜 2　检索：把研究问题变成检索计划（0:50—2:00）

- 画面操作：
  1. 打开 `/app`，在检索框输入：
     `图神经网络预训练方法在分子性质预测小样本场景下的适用性`，年份设为 2020—2026，点击检索。
  2. 检索进行中，指一下右侧“知识上下文”里显示的检索来源（arXiv / OpenAlex / Crossref / Semantic Scholar / 本地索引）。
  3. 结果出来后，展开一条推荐的“推荐理由”，指出理由里的原文片段。
- 旁白：
  “系统先把研究问题拆成主题、方法、研究对象和年份约束，再并行检索多个学术来源，
  合并重复、沿参考文献继续找线索，最后按研究用途排序。
  注意每一条推荐下面都写着理由，理由用的是这篇论文标题或摘要里的原文——
  引用量高、期刊好，不能替代‘它回答了你的问题’。
  如果某个来源超时，其他来源照常返回；全部失败时它会直接说没有结果，不会给你一篇不存在的论文。”

## 分镜 3　课题工作台：证据与阅读（2:00—3:10）

- 画面操作：
  1. 把 2—3 篇文献加入课题项目，进入项目“阅读”页。
  2. 打开一篇 PDF，选中一句结论，保存为证据（显示页码与片段）。
  3. 进入“研究矩阵”，指出某一行是刚才的证据生成的概括，旁边能点回原文。
  4. 修改一处矩阵单元格，说明人工修订不会被批量重跑覆盖。
- 旁白：
  “选中的文献进入课题项目，PDF 按页阅读，选中的原文保存为证据，带页码、带原文。
  系统不允许提交原文里没有的片段，这是硬性校验。
  矩阵、问答、综述、演示都指向这些证据，所以任何一句概括都能点回出处；
  人工改过的内容会被保留，不会被模型覆盖。”

## 分镜 4　成果：综述与演示（3:10—4:10）

- 画面操作：
  1. 生成综述草稿，指出章节与引用标记，导出 Word。
  2. 生成组会演示草稿，翻两页，指出页面备注里的出处。
  3. 导出 PPTX，用 PowerPoint 打开，说明是原生可编辑文本框。
  4. 回到项目，把一篇文献的来源版本变化，指出“待复核”提示。
- 旁白：
  “综述按章节组织已有证据，导出的是可以继续改的 Word。
  演示稿导出原生 PPTX，每页备注里保留出处，组会汇报可以直接用。
  如果来源文件或版本发生变化，依赖它的成果会被标记为待复核，
  人工确认之后才重新生成——结论过期这件事，系统会提醒你。”

## 分镜 5　工程与可信（4:10—4:45）

- 画面：PPT 第 12 页（系统架构）、第 14 页（验收进展）。
- 旁白：
  “架构上，网页和 MCP 工具共用同一条检索链路，前后端分离，数据可以存本地，
  也可以用容器部署 PostgreSQL 和私有对象存储，适合课题组私有化使用。
  截至 2026 年 11 月 3 日，仓库回归测试 148 项全部通过，其中 24 项是完整用户流程；
  模型不可用时，系统降级到原文整理并标注实际生成方式。”
  补充一句现状（照实说）：
  “浏览器全流程复跑、真实检索覆盖率和云端模型质量评测还在推进，
  这些差距我们也写在计划书里。”

## 分镜 6　收尾（4:45—5:00）

- 画面：PPT 最后 1 页（把研究过程变成可回溯的工作流）。
- 旁白：
  “研索不替研究者下结论，它让结论有出处、有复核、能继续用。
  研索 ScholarScope，从研究问题到可核对的研究成果。”

## 录制清单

- [ ] 关闭通知与无关窗口，浏览器缩放 100%，清空演示用的检索历史（或使用新账号）。
- [ ] 麦克风先试录 10 秒，确认无底噪、无回声。
- [ ] 视频里不要出现密钥、`.env`、Zotero API Key、模型配置页的 Key 输入框。
- [ ] 数据准备：至少 3 篇可解析的 PDF 在项目里，检索可用的模型与数据源已配置。
- [ ] 导出：H.264 MP4，1920×1080，30fps，码率 ≥ 8 Mbps；音量峰值 −6dB 左右。
- [ ] 命名：`研索ScholarScope-作品介绍视频.mp4`，与 PPT、计划书一起打包。
- [ ] 提交前用播放器完整看一遍：无黑屏、无静音段、无报错弹窗。
