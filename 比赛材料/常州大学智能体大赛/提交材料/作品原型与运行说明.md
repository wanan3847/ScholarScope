## 一、作品形态

本次提交的是**可运行 Web 智能体原型**，另附 MCP 服务入口供外部编辑器调用。两者共用同一条检索与任务链路。

| 形态 | 入口 | 用途 |
| --- | --- | --- |
| Web 工作台（主演示入口） | `http://127.0.0.1:8765/app` | 输入研究问题、执行检索任务、阅读论文、查看证据、生成矩阵与文稿 |
| 产品首页 | `http://127.0.0.1:8765/` | 说明与入口页 |
| MCP 服务（stdio） | `python mcp_server.py --transport stdio` | 在 Claude Code / Cursor 中直接调用检索工具 |
| MCP 服务（SSE） | `python mcp_server.py --transport sse --port 8766` | 远程调试调用 |

作品不要求永久线上部署，评委现场或视频演示均在本机运行；如需在线访问链接，可在评审前按第九节部署到任意支持 Python 3.14 的主机，并在提交材料中补充该链接。

## 二、运行环境

- Python 3.11 及以上（本机实测 3.14.4）
- 可选：Node.js 20+（仅在需要重新构建前端时使用；仓库已包含构建产物 `src/web/static/ui/`，直接运行不需要 Node.js）
- 可选：Poppler + Tesseract（扫描版 PDF 的 OCR 与排版解析）
- 网络：访问 arXiv、OpenAlex、Crossref、Semantic Scholar、Europe PMC 的公开接口
- 可选：本地 Ollama 或任意 OpenAI 兼容云端 API Key（用于模型判断；不配置时按文本匹配降级，检索与阅读仍可用）

## 三、启动步骤（三步）

```bash

cd src
pip install -r requirements.txt

# 2. 启动服务
python3 -m uvicorn web.app:app --host 127.0.0.1 --port 8765

# 3. 浏览器打开
#    首页：      http://127.0.0.1:8765/
#    工作台：    http://127.0.0.1:8765/app
#    服务健康：  http://127.0.0.1:8765/api/health
```

2026-11-03 实测：按上述命令启动后，`/` 与 `/app` 均返回 200，服务启动无报错。

## 四、演示路径（评委现场 6 步，约 4 分钟）

1. **输入研究问题**：在工作台搜索框输入一个带约束的研究问题，例如
   `图神经网络预训练如何改善分子性质预测？`
   注意它包含研究对象（分子性质预测）、方法（图神经网络预训练），而不是关键词堆叠。
2. **查看查询规划**：展开查询规划，确认系统把问题拆成了聚焦检索短语，并保留了方法约束与年份条件。
3. **观察工具执行**：检索进行中出现分阶段进度，可见并行调用了哪些学术来源、每轮新增/重复/拒绝数量，以及是否触发补检索。
4. **核对推荐理由**：打开任一文献的推荐理由，展开证据片段，确认理由里的每句话都能在检索到的标题或摘要中找到对应原文。
5. **落入课题**：把文献加入项目，生成对比矩阵，任一单元格都带原文出处；修改证据后，依赖它的产物会被标记为待复核。
6. **交付产物**：生成综述草稿与演示报告，导出 DOCX / PPTX / Markdown，检查导出文件中的来源备注。

## 五、功能与操作要点

- **检索**：支持年份区间、模型选择、高级筛选（数据库来源、方法词、引用次数、代码链接）。年份条件下发到 arXiv、OpenAlex、Crossref 并在合并后复核；日期缺失的文献在指定年份时不进入结果。
- **阅读**：点击文献进入阅读面板，查看完整摘要、推荐理由与证据片段；支持收藏、标记已阅、引用导出、独立阅读窗口。
- **文献库**：按课题建文件夹；导入 BibTeX / RIS / CSV / JSON；导出全部收藏或单个文件夹。
- **科研项目**：创建项目、邀请成员（owner / editor / viewer）、上传 PDF 按页阅读、保存页码证据、生成比较矩阵、跨论文原文问答、综述编辑、图表与 12 页演示报告。
- **设置**：页面内注册模型端点（含预设提供商与自定义模型 ID）、配置学术数据源密钥、设置优先级；密钥只填表单，不回显。

## 六、账号与数据

- 首次使用可注册账号，或直接以未登录状态使用共享匿名空间。
- 收藏、已阅、文件夹、笔记与导入按账号隔离；项目数据按角色隔离。
- 运行数据默认保存在 `src/data/`（不入库、不提交）。管理员账号仅在显式设置 `SAKURA_ADMIN_PASSWORD` 时创建。

## 九、如评委需要在线链接

在任一台可联网主机上执行 `docker compose up -d --build`，或将 `src/` 以 `uvicorn web.app:app --host 0.0.0.0 --port 8765` 运行，再用反向代理暴露 HTTPS 地址即可。演示期间建议只开一个任务，避免与本机 Ollama 抢占推理资源。

## 十、已知限制（如实说明）

- 未配置模型时系统按文本匹配降级，推荐理由质量下降，但不会编造论文。
- 浏览器端到端用例（`src/tests/run_acceptance.py` 中 5 组 Playwright 脚本）本轮执行环境受端口限制未运行，脚本本身语法检查通过。
- 私人 Zotero 账号的双向同步需自备 API Key 后单独联调，当前验收覆盖官方公共接口与接口契约。
- 综述与演示报告的 AI 综合可能只覆盖部分章节，缺口在界面与导出结果中如实标注；草稿仍需研究者完善论证。
- 真实检索质量受领域长尾影响。已有记录：以"深度学习测井曲线预测孔渗参数"为目标 30 篇的验收中，补检索在约 210 秒、3 轮内保存 10 个真实候选，未达到目标数量，系统保留实际状态而未凑数。
