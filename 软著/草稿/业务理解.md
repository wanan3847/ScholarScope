# 业务理解

- 软件名称：智能学术文献检索与分析软件
- 产品定位：面向科研工作者的端到端学术文献检索、引文扩展与排序分析平台：对复杂学术查询做理解、多渠道检索、迭代扩展与结构化结果展示，并支持反馈使用跟踪与模型评测。
- 面向领域 / 行业：学术信息服务 / 科研数据智能检索与知识服务
- 核心价值：把“一段复杂、模糊的学术问题”处理成一次多源检索与引文扩展：先理解查询意图，再从真实学术数据源召回候选，随后沿引用关系迭代扩展论文网络，最后用统一的比对与关系视图帮助研究者高效定位相关文献。
- 证据文件：`业务理解证据.md`

## 目标用户

- 科研工作者与高校师生
- 开展文献调研与综述的研究者
- 情报检索与知识管理研究人员

## 主要业务功能

- 复杂学术查询理解与查询规划
- 多渠道文献检索与语义预排
- 迭代式引文双向扩展
- 结构化三件套结果输出
- 检索反馈使用跟踪与个性化收集
- 多模型评测与离线复现

## 功能说明

- 复杂学术查询理解与查询规划：把用户的描述性学术问题解析为关键词检索词与语义短语，形成可执行的查询规划。
- 多渠道文献检索与语义预排：并发访问 arXiv、OpenAlex、CrossRef、Semantic Scholar 等真实学术接口并配合本地语义语料检索，随后按语义相关性预排序。
- 迭代式引文双向扩展：对命中论文网络进行被引用与引用的双向扩展(RefChain)，逐层扩大相关文献范围，接近多轮迭代检索的效果。
- 结构化三件套结果输出：把查询与检索结果整理为 JSON、Markdown 对比表和自包含 HTML 关系图，可离线打开。
- 检索反馈使用跟踪与个性化收集：记录用户对检索结果的点击、复制、引用、跳过、星级等反馈事件，支持对结果做收藏与个人库沉淀。
- 多模型评测与离线复现：内置学术基准评测集与可离线运行的评估流水线，支持多模型对照，帮助使用者评估检索与排序效果，且无外部服务时仍可复现基础结果。

## 典型操作流程

1. 在应用入口输入一段学术问题或补全任务所需信息；未配置大模型时可离线演示。
2. 如提示需要访问真实文献库或大模型，先在 Web 端配置或切换对应的数据源接口与模型供应商。
3. 提交查询后查看检索进度：系统先做查询理解，再多渠道召回并结合语义预排。
4. 在结果页查看 JSON 明细、Markdown 对比表与关系图，沿引用与被引继续扩展相关文献。
5. 对感兴趣的记录进行收藏、复制或标注反馈，形成个人文献库。
6. 如需检验效果，在主/命令行入口运行内置评测集，比较不同模型或策略的结果。

## 操作手册页面/流程模块

1. Web 端检索与结果页（主工作台）：启动 Web 服务后在浏览器打开入口页面进入检索主界面。
   - 使用场景：研究者想对一个具体学术问题做系统检索，并查看命中文档的关系图、对比表，或对结果收藏/反馈时使用。
   - 操作要点：在输入区输入一段学术问题。；如需真实检索或调用大模型，先在配置区登记并选择可用的数据源和模型供应商。；点击发起检索，等待系统完成查询规划、多路召回与引文扩展。；在主界面切换 JSON 明细、Markdown 对比表与关系图查看命中结果。
2. 命令行与编程接口：检索、评测与收藏：安装依赖后，在本机启动命令行或本地服务入口，按文档用相应命令或工具名调用。
   - 使用场景：使用者想让结果直接进入自己的脚本、让第三方界面一键调用检索能力，或在电脑上批量跑某评测集比较模型时使用。
   - 操作要点：启动命令行或本地服务并确认连接成功。；调用检索能力输入欲查询的学术问题，按返回取用结果。；按需调用单篇详情、参考文献或被引以扩展某条文献。；调用收藏能力把关注的论文加入个人库。

## 申请表建议口径

- 开发目的：把科研人员提出的学术检索需求，转成可执行查询规划，跨真实学术数据源召回、扩展并按统一结构化视图展示相关文献。
- 软件的主要功能：软件面向科研文献调研与检索场景，提供端到端检索与分析能力。研究者输入一段描述性的学术问题后，软件运用查询理解做关键词与语义短语规划，随后并发访问 arXiv、OpenAlex、CrossRef、Semantic Scholar 等真实学术数据源并结合本地语义语料执行多路召回，再按语义相关性预排序并沿引用－被引用关系做迭代扩展(RefChain)，把命中论文组织成 JSON、Markdown 对比表以及可离线浏览的关系图等结构化结果。软件内置常用大模型供应商与真实检索接口的接入与配置管理，支持把检索出的文献收藏沉淀到个人库，并通过记录点击、复制、收藏等反馈持续改进与回顾检索效果。使用大型模型接口时可配置对应供应商；在无网络或未配密钥的环境下仍能以离线模式复现部分检索与评测能力，便于研究者校验结果。
- 技术特点：软件把检索任务拆为查询规划、多路召回、语料预排、引文扩展与结构输出几个环节：查询层做关键词+语义短语规划，召回层衔接多个真实学术 API 与本地倒排/向量语料并做预筛保底，扩展层基于引文网络做双向(引用/被引)扩展以逼近多轮迭代检索，输出层统一生成 JSON、Markdown 与自包含 HTML 关系图；整体采用可替换的大模型/真实数据源抽象，支持离线 Mock 与真实供应商两用，便于可控复现与评测。
- 软件的技术特点选项：应用软件
- 软件分类：应用软件
