## 复现

```bash
# 1. 起服务
cd src && python3 -m uvicorn web.app:app --host 127.0.0.1 --port 8765
# 2. 拍 Web 截图（Playwright，无头 Chromium）
node 软著/截图/_shot_ui.js
node 软著/截图/_shot_ui2.js
# 3. 拍命令行截图
node 软著/截图/_shot_cli.js <输出文本> <输出png> [标题]
# 4. 把截图写回操作手册（幂等，自动备份）
python3 软著/补齐操作手册.py
```
