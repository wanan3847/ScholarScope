# 用户验收测试计划与执行报告

日期：2026-10-14。范围：根任务书 T01–T30、首页、检索工作台和科研项目全部功能。根 [README](../../README.md) 为项目入口。

## 方法和放行标准

采用需求追踪、风险优先的分层测试：既有单元/契约回归 → 实际应用接口的用户旅程 → 浏览器操作与兼容性 → 真实服务及研究结果质量。正常流程、空输入、错误文件、重复导入、过期版本、跨账号访问、只读成员、外部失败及来源失效均纳入。验收不能仅以按钮存在、HTTP 200 或模拟接口返回成功判定。

- `PASS`：预期行为、持久数据或导出文件内容已核对，证据可重复执行。
- `FAIL`：测试实际执行后，产品行为或测试设施错误使断言不成立；必须先区分原因。
- `BLOCKED`：缺少运行条件，未完成对应验收。不会算作通过或用旧截图代替。
- 放行要求：当前构建回归无失败；关键用户旅程、桌面/移动端、当前部署和真实研究场景均通过，无未解决的关键缺陷或关键阻塞。T30 在放行条件满足前保持未完成。

## 测试环境与隔离

应用：真实 FastAPI/ASGI，实际认证、SQLite、私有对象文件、PDF 解析器、文稿/PPT/图表导出器及任务子进程。接口旅程通过 ASGI TestClient 发起 HTTP 请求，不替换业务端点、认证或生成文件的实现；该层证明实际后端行为，**不能证明浏览器用户体验通过**。

数据：每条旅程独立临时目录，真实注册 owner/editor/viewer/outsider 及配置管理员。使用明确标为受控的文献、实际两页 PDF、已知样本数及模型指标；没有写入用户账号、文献库或私有 Zotero 库。云端 API 和本机模型生成在本轮关闭：研究功能验证原文整理降级的真实性，不据此评价模型语义质量。存储与账号文件从运行数据中隔离，未输出凭据。

实际阻塞：本轮本地 socket bind 返回 `PermissionError (errno=1)`，无法启动隔离 HTTP 服务。因此浏览器用例只完成语法检查，操作、画布渲染、截图、交互及视口检查均未获得当前运行证据。

## 执行结果与证据

首轮新增旅程：13 通过、6 失败（26.29 秒）。六项均为测试预期错误：已阅条目是对象数组；非法角色先返回 400；非成员/撤权后返回 404 以隐藏项目存在性；BibTeX 导出格式 ID 为 `bib`；全文获取字段名为 `records`。对照实际前端调用及接口约定修正测试，没有将这些用例错误写成产品缺陷。重跑 19 条全部通过（25.77 秒）。新增 U20 四格式真实往返均通过（2.47 秒）。

第一轮正式执行：143 项回归通过，生产构建、内联 JavaScript 和四套既有 UI 语法通过。证据保留在 `.cache/acceptance/2026-10-14-formal/`。纳入 U20 及新增账号设置 UI 脚本后，147 项通过（44.35 秒），8 个自动检查阶段通过，9 个阶段阻塞；证据在 `.cache/acceptance/2026-10-14-final/`。发现并修正下述检索异常缺陷后的完整复验在 `.cache/acceptance/2026-10-14-reviewed/`，以其 `report.json`、`regression.xml` 与日志为准。 最新复验 **148 项通过（45.13 秒）**，其中 **24 条用户流程用例全部通过**；构建、内联 JS 及五套 UI 语法检查共 **8 个阶段通过**，五套浏览器运行与四类真实环境验收共 **9 个阶段阻塞**，总体状态 `INCOMPLETE`。

### 本轮产品缺陷和复验

U21 故障注入复现：检索阶段抛出的原始异常被放入 HTTP 500 的 `detail`，同时异常堆栈进入日志。注入的受控敏感标记因此可传播；这是异常处理路径的缺陷，不表示用户真实密钥曾泄漏。修复后改为不包含异常原文的 HTTP 503 中文提示和固定日志，保留无结果失败行为，不创建替代论文。U21 修复前失败（0.96 秒），修复后通过（0.88 秒）；前后证据分别在 `.cache/search-failure-acceptance-before.log` 与 `.cache/search-failure-acceptance-after.log`，随后进行全量复验。

总体结论：**未完成全范围验收，不能宣称全部功能用户实测通过或达到市场同等效果。** 后端用户流程与真实文件获得当前证据；浏览器、在线检索、真实模型、实际私有 Zotero 库及当前容器部署是独立未验收项。真实模型测试沿用用户此前“使用真实 API 自行测试”的安排，本轮未重新加载或下载大模型。

## 重复执行

在仓库根执行：

```bash
.venv/bin/python src/tests/run_acceptance.py
```

执行器自动隔离数据，运行全量回归、构建和 JavaScript 校验；能够监听本地端口时启动自己的隔离服务，并执行五套 Playwright 用例。只关闭自己启动的服务，不修改用户服务或文献库。输出保存在 `.cache/acceptance/<绝对日期和时间>/`；退出码 0 表示本次范围全部通过，1 表示执行失败，2 表示仍有阻塞。`report.json` 分开统计回归用例及检查阶段，避免把未执行浏览器算作通过。

自动执行器刻意保留真实研究质量与部署验收为 BLOCKED：正式联网验收应使用独立测试项目，人工核对“近三年测井曲线预测孔隙度/渗透率”查询的主题、方法、对象和年份；真实不足 30 篇保留实际数量。对矩阵/问答/综述/PPT 逐条回查出处，统计错误与完整性；Zotero 从只读检查和增量导入开始，写入测试使用明确的测试集合。访问权限、凭据或研究原文缺失时保留未验收状态，不提供替代性假数据。
