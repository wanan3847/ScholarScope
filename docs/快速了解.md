# SakuraPaper 快速了解（给下一个 Agent）

> 面向"科研场景下复杂学术查询"的多 Agent 论文检索系统（研究生创新实践大赛参赛作品）。
> 本文档是给接手 Agent 的快速上手材料；完整入口文档是根目录 `README.md`，
> 运行时约定见根目录 `AGENTS.md`，评测记录见 `docs/评测记录.md`。

## 1. 项目是什么

- 用户输入复杂的科研问题（如"RAG 2023 之后的综述"），系统返回结构化的论文集合。
- 检索由 **SPAR2 引擎**完成：查询规划 → 并行 5 通道检索 → BGE 语义预筛 →
  LLM 批量判分 → RefChain 双向引文 → 精排 → 结构化三件套（JSON / MD 表格 / 文献星图）。
- Web 端（FastAPI + 单页前端）提供搜索、收藏夹/文件夹、导入导出、已阅、账号、
  API Key 设置、大模型配置等功能。

## 4. 关键事实（2026-08-23 状态）

- **SPAR2 引擎**：5 通道并行（40s/通道硬超时）+ 迭代检索（最多 3 轮 BFS）+
  文档驱动查询 + RefChain 双向引文（API 2 跳）+ BGE 语义预筛（0.70/0.20/0.10，
  阈值 0.40）+ LLM 三维判分 + deadline 逐批截断；本地 ollama 自动跳过精排/双规划。
- **Web 界面**：温暖学术风格（#F5F1E8 纸张、Crimson Pro、🌸），首页与搜索页
  顶栏布局一致、图标互跳（`/app#favorites|history|settings|docs|model`）。
- **收藏/账号**：按账号隔离（user_id）；默认收藏文件夹（`/api/folders/default`）；
  导入/导出跟随账号与文件夹；导出文件名用文件夹名。
- **账号体系**：注册/登录/修改密码/登出；内置管理员 admin（凭据在 `.env` 的
  `SAKURA_ADMIN_USER/PASSWORD`，未配置时默认 admin/admin123），登录后可在
  文档弹窗里编辑使用手册（`src/data/docs_content.json`）。
- **API 配置**：设置 → 检索通道 页直接填 OpenAlex / S2 key，存
  `src/data/api_config.json`，检索后端优先读它、回退 .env。
- **评测现状**：RealScholarQuery DeepSeek 20 条三件套 F1@10=0.1055、
  本地 qwen3 全量 50 条 F1@10=0.0893（详见 docs/评测记录.md）。
- **测试**：32 个用例全绿；`tests/ad_hoc/` 不参与 pytest 收集（见 pytest.ini）。

## 5. 约定（改代码前必读）

- 文档用绝对日期，不留"今天/最近"。
- 检索后端失败必须静默降级（`_safe_call` / 熔断器），不能拖垮整条流水线。
- 前端不依赖浏览器 API 做关键逻辑；改模板后必须
  `node --check` 校验内联 JS（提取 `<script>` 后检查）。
- 收藏/已阅等 ID 路由一律用 `{paper_id:path}`（DOI 带斜杠）。
- 新增运行时数据文件记得加进 `.gitignore`。
- ad-hoc 脚本放 `src/tests/ad_hoc/`，构建脚本放 `scripts/`。
