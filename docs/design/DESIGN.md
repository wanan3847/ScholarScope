# 研索前端设计语言

更新日期：2026-10-13
状态：已实现首页与工作台，共享 Atelier Zero 品牌资源。

## 设计来源

本次用户提供的 `Open-Design-Landing.zip`（同目录） 是视觉依据，取代此前瑞士国际主义草案。首页直接延续导出 HTML 的布局、文案主线、拼贴、章节、字体比例与响应式规则；工作台延续同一品牌语言，同时保留科研阅读所需的信息密度和交互。功能及数据边界见 [科研文献工作台设计](research-workspace.md)。

## 两个页面

- `/`：独立编辑式首页。拼贴封面、研究理念、四项工具、五条研究路径、研究步骤、场景切换、研究原则和工作台入口。
- `/app`：文献工作台。左侧研究导航，中间检索和列表/方法对比，右侧阅读/知识上下文。
- 首页产品操作连接真实工作台，文献库进入 `/app#favorites`，导入进入 `/app#import`，研究路径可用 `/app?q=...` 发起检索。首页两篇预览文献明确标注阅读示意，不混入搜索结果。
- `/app#login`、`#settings`、`#model`、`#docs` 支持直接打开相应面板。

珊瑚底主按钮使用深墨色文字；文字链接用较深珊瑚色，以保持可读性。选中导航用墨色底，选中文献用骨色表面与珊瑚侧线。状态同时使用图标或文字，不只依赖颜色。首页保留导出设计的轻纸纹理，工作台的长篇阅读区保持实色。

所有关键颜色有直接 CSS 色值，不依赖相对 OKLCH 等实验性颜色语法。

## 字体与品牌

- Inter Tight：首页展示标题和工作台文献标题。
- Inter：正文、导航与控件。
- Playfair Display：斜体编辑强调、罗马章节及数量。
- JetBrains Mono：技术元信息。
- 中文按系统无衬线/宋体回退；字体文件和 OFL 许可本地提供。
- 品牌记号延续封面的圆形 Ø，首页与工作台一致。

字体位于 `frontend/public/brand/fonts.css`，插画为同目录下的 `research-collage.jpg`。前端不加载远程字体或 CDN。

## 排版、形状与动效

首页保留导出设计的非对称封面、衬线强调、罗马章节、点状细线、圆形箭头和胶囊主按钮；主体最大宽度与间距沿用导出的 `.wrap`、网格和流式字号。

工作台采用连续文献行，细分隔与对齐建立层级。主/次按钮为胶囊形，输入框和标签为 3–4px 圆角，对话框为 6px 圆角。弹窗可有轻阴影，阅读区不使用玻璃或辉光。普通列表标题约 17px，阅读标题 21–23px，展开阅读标题 28px，摘要 14px / 1.95。

首页内容始终可见，章节活动状态由 IntersectionObserver 增强。工作台仅有短暂状态反馈与面板淡入；遵守 `prefers-reduced-motion`，不使用滚动劫持或无限装饰动画。

## 响应式与功能状态

桌面整体固定高度，导航、文献列表与阅读器独立滚动。宽屏阅读栏 450px，普通桌面为 384px；1024px 以下采用列表与阅读互斥切换，768px 以下单列与页面滚动。手机保留导入、帮助、设置、登录和文件夹管理入口。

输入、按钮、标签页与对话框保持键盘可达；图标按钮提供可访问名称，选中态可辨，焦点环可见。加载、取消、空结果、失败、资料缺失与降级使用真实状态。关键功能沿用原 API 和数据保存范围。

## 实现与验证

- 首页源码：`frontend/landing.html`；样式和交互：`frontend/public/brand/landing.css`、`landing.js`。
- 工作台源码：`frontend/src/`；基础样式 `style.css`，品牌扩展 `atelier.css`。
- 构建：`node scripts/build_frontend.mjs`，分别安装首页与工作台，复制共享本地资源。
- 回归：`cd src && python3 -m pytest tests/ -q`。
- UI：`node src/tests/ui_smoke.js`、`node src/tests/ui_research.js`、`node src/tests/ui_landing.js`，先启动服务。
- 首页与工作台覆盖 360、390、430、600、820、1024、1366、1440、1920px；受控响应检查检索、阅读、资料管理、深浅色、错误与取消，不修改真实账号或文献库。
- 模板内联脚本提取至 `src/tests/ad_hoc/inline_js/` 后运行 `node --check`；首页独立脚本同样校验。

截图输出到 `.cache/ui-check/screenshots/`。其中检索、图表和笔记测试使用明确标注的测试文献。
