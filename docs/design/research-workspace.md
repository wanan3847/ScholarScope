# 科研文献工作台设计

更新日期：2026-10-13

## 设计依据与现状审计

使用 `design-taste-frontend`（Taste Skill）的简报推断、重新设计审计、统一颜色和形状、可访问性与交付检查。视觉依据 `Open-Design-Landing.zip`（同目录） 的 Atelier Zero 品牌规范，工作台用原生 CSS 延续首页的暖纸色、墨色、珊瑚色与编辑排版。

原界面已有 React、Radix、Phosphor 与本地 Geist 字体；主导航是检索、文献库、历史，收藏、已阅、文件夹、账号和导入导出已连通。原布局偏低密度，大型多行搜索区、结果与详情的等宽分栏、页面级滚动降低了阅读空间。保留中文操作语言、现有路由和关键按钮 ID；首页与工作台分为 `/` 和 `/app` 两个独立页面，共享品牌与本地字体资源。

设计参数：`DESIGN_VARIANCE: 3`、`MOTION_INTENSITY: 2`、`VISUAL_DENSITY: 8`。这是桌面专业工具，适用 Taste 的审计和克制原则；营销 Hero、摄影、滚动叙事等条目不适用。

## 布局与视觉

- 左栏 224px：检索、文献库、历史、保存的检索、课题文件夹、方法主题与笔记标签。
- 中栏：研究问题输入、年份、模型、高级元数据筛选；连续文献列表或方法对比表。
- 右栏 384px：文献阅读器与知识上下文，通过键盘可操作的 Radix Tabs 切换。
- 桌面导航与检索工具栏固定；列表和阅读器独立滚动。宽屏放大阅读栏，窄屏切换列表和阅读器，手机使用页面滚动。
- 普通阅读器可展开；独立阅读窗口沿用 `/app?reading=论文ID`，支持同时打开多篇论文。

浅色：纸色 `#efe7d2`、骨色 `#f7f1de`、墨色 `#15140f`、珊瑚色 `#ed6f5c`；深色采用暖墨底与浅纸色正文。主操作为珊瑚色胶囊按钮，次操作用细边框；点状分隔用于章节与导航分区，列表仍以连续行呈现。Inter / Inter Tight 为正文和标题字体，Playfair Display 为编辑式强调与数量，JetBrains Mono 用于技术元信息；全部本地提供，中文使用系统字体。工作台仅做状态反馈，尊重减少动效偏好。封面拼贴只出现在首页和未检索时的引导区。

## 数据与研究证据

- 文献条目包含标题、作者、venue、年份、摘要、研究用途、引用次数、方法、数据集、代码链接和收藏/已阅操作。缺失数据明确显示未提供，不补造数字或论文。
- 推荐顺序沿用 Agent 的研究用途选择；引用量仅用于用户主动的结果筛选。
- 数据库、方法、最低引用次数、代码过滤应用于已返回文献的元数据。年份约束仍发送给搜索 API。界面注明此范围，筛选不代表数据库全量检索或完整代码覆盖。
- 方法主题来自明确元数据，或标题/摘要中出现的已知方法词。概念图表示这些方法词与论文的对应关系，不是自动发现的科学结论。
- 贡献、方法、算法区域展示摘要句子摘录，不推断缺失内容；数据集仅使用检索元数据。
- 文献关系图只绘制响应中可核对的边；文本相似、共同作者与引文分开。不存在引文边时展示空状态，不把相似关系冒充引用关系。
- 时间图是当前结果的发表年份分布，不代表整个研究领域的趋势。

## 工作流与保存范围

快捷键：`Cmd/Ctrl K` 聚焦检索；列表中的上下键选择论文，Enter 打开阅读，Escape 返回窄屏列表。每项图节点可用键盘选择。收藏、已阅、文件夹、账号、文献文件导入导出继续使用原有 API。

保存的检索记录问题和年份条件。阅读器支持笔记、摘要选中摘录、阅读进度和逗号分隔标签；标签可以筛选当前文献列表。新增资料按账号在当前浏览器中保存，独立窗口同步笔记修改。笔记、标签与保存的检索不随 BibTeX/RIS/CSV/JSON 导出；不是服务器同步资料。独立窗口从当前账号的本机缓存读取论文，无法作为跨设备分享链接。

## 验证

- 构建：`node scripts/build_frontend.mjs`。
- 回归：`cd src && python3 -m pytest tests/ -q`。
- 界面：先启动服务，运行 `node src/tests/ui_smoke.js` 、`node src/tests/ui_research.js` 与 `node src/tests/ui_landing.js`。均使用受控响应，不修改真实账号或文献库。
- 后者覆盖查询/年份校验、保存检索、键盘操作、四类元数据筛选、对比表、关系图和概念图、笔记/摘录/进度、标签、独立阅读、刷新恢复与账号隔离，以及 1920、1280、1024、768、390px、深浅色、空结果、失败和取消。
- 模板更新后提取内联脚本执行 `node --check`。

截图位于 `.cache/ui-check/screenshots/`，关系图和对比图使用明确标注的测试文献，不是线上检索结果。
