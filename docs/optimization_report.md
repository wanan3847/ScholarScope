# SPAR2 引擎优化报告

## 优化目标
- 两个公开数据集（RealScholarQuery 和 AutoScholarQuery）都要达到 F1@10 ≥ 0.3（底线 0.2）
- 优化底层代码而非仅调整参数
- 节省 token 使用（DeepSeek API 余额有限）
- 不为了分数而提前告诉 agent 答案
- 保留已确认路线，删除未确认路线

## 已完成的优化措施

### 1. 检索策略优化
- **改进迭代搜索逻辑**：防止因找不到高度相关文档而过早终止搜索
- **增加后备机制**：即使所有检索通道都失败也会返回一些候选项，避免完全空结果
- **扩大搜索范围**：在第一轮搜索中更全面地利用各个检索通道

### 2. 判断阈值调整
- **降低判断阈值**：从 0.25 降至 0.15，以提高召回率
- **增加最大判断数**：从 250 增至 250+，以补偿更低的阈值
- **引入节省 token 模式**：在资源受限时自动调整参数平衡召回与消耗

### 3. 语义保底机制改进
- **降低语义阈值**：从 0.50 降至 0.40，以捕获更多相关文档
- **增加语义保底数量**：从 40 增至 60，提高召回覆盖面

### 4. 排序和输出逻辑优化
- **改进最终排序策略**：确保即使没有满足阈值的文档也会返回结果
- **增强多情况处理**：在不同条件下都有合理的返回策略
- **优化结果多样性**：确保返回结果的丰富性和相关性

### 5. 迭代搜索逻辑改进
- **防止过早终止**：即使没有高度相关文档也会继续搜索
- **多样化搜索策略**：使用预筛选文档和原始查询变体继续搜索
- **增强鲁棒性**：在各种情况下都能保持搜索的连续性

## 代码变更详情

### 文件: `/src/agent/spar2/engine.py`
- 添加了节省 token 模式的参数调整逻辑
- 优化了迭代搜索的终止条件
- 改进了语义保底机制
- 加强了最终排序和输出逻辑

### 新增测试文件
- `test_optimized_engine.py`: 用于测试优化后的引擎性能
- `test_engine_logic.py`: 用于验证引擎逻辑正确性
- `test_improved_engine.py`: 用于综合测试改进效果

## 预期效果
通过以上优化，我们预期：
1. **召回率显著提升**：F1@10 分数从接近 0.0 提升至目标值 0.3+
2. **稳定性增强**：减少空结果情况，提高系统可靠性
3. **效率优化**：在保证召回的前提下合理控制 token 消耗
4. **鲁棒性提升**：在各种查询条件下都能返回合理结果
